工坊全流程教程指南 (v2.1.3)
📖 耳机の生成工坊·全功能官方使用手册 (v2.1.3)
点击下方各个 App 卡片，即可展开查看每个应用的最新用法、生成技巧与联动逻辑！
1. uu生成器 (User 人设定制与社交圈)
【功能概述】：为玩家主角（User）定制高维度陪伴人设，支持套用自建 User 模板，并能一键生成 1~5 位知心挚友圈。
【操作步骤】：
① 绑定/独立生成：选择绑定的 Char（若选择多人卡，将生成能融入该多人羁绊的 User），或点击“不绑定char”自由发挥；
② User 模板选择：支持下拉选择在【模板自定义】中保存的专属 User 模板，打造固定格式的玩家档案；
③ User 人际关系生成：切换至分区二，选择目标 User 与期望人数（1~5人），一键推演闺蜜/发小/知己好友圈与前尘羁绊故事。
【数据归档】：转入桌面「user预览」中管理、导出 Word (.Docx) 或纯文本 (.Txt)。
2. char生成器 (单人 / 多人 / 选项人设双引擎)
【功能概述】：工坊核心角色创作引擎，支持大纲直出流与标签点选流，内置耳机模板、吻我涙模板及全部自建模板。
【操作步骤】：
① 单人模式：填写名字、大纲，可上传头像并开启 AI 识图外貌填充，选择心仪模板生成；
② 多人模式：点击右上角“多人模式”，添加多位角色并填写相互关系，一次性生成群像卡；生成后支持子角色分 Tab 预览与独立导出；
③ 选项人设生成：切换至分区二，支持自由点选性别、性取向、年龄、塑形倾向、性格与职业，支持自建大分类与小标签。
【数据归档】：保存进「char预览」，支持世界书与开场白级联生成。
3. 世界书生成器 (人设配套设定 & 普通世界书)
【功能概述】：构建城市、工作地点、人设补充、关系网等设定集，支持外部本地卡导入，提供独立普通世界书仓库。
【操作步骤】：
① 人设配套世界书：选择目标 Char，点击「城市设定」「工作地点」「人设补充」「关系网」等按钮分别生成，自动归档进该角色卡；
② 普通世界书：切换至分区二，输入大标题与规则大纲生成通用世界书，右上角 3D 纸箱仓库支持分组、多选与批量导出 Word/Txt；
③ 外部卡导入：支持上传本地 Docx/Txt 格式外部角色卡，自动解析转存。
4. 生图功能 (AI 生图与相册管理)
【功能概述】：支持基于 DALL-E 3 或第三方生图 API 快速产出高质感角色立绘与场景画作。
【操作步骤】：
① 输入人物外貌动作提示词，选用内置真实感或日系平涂修饰词；
② 选择画面比例（16:9 / 3:4 / 2:3 或自定义），点击「启动 CoT 并生图」；
③ 点击底部按钮可进入「生图相册」，支持全屏大图预览、独立删除、分组管理及多选批量下载。
5. 世界观生成器 (普通 & IF线世界观)
【功能概述】：为故事构筑宏大的世界法则、势力格局与社会背景。
【操作步骤】：
① 普通世界观：可绑定现有主角 Char 或独立生成，输入大纲后生成世界背景；
② IF线世界观：绑定指定角色的 IF 线变体标签，定制专属平行宇宙背景法则；
③ 生成后点击保存，自动转存并挂载进对应 Char 预览卡片中。
6. 开场白生成器 (多人联动 & 文风描写加持)
【功能概述】：融合主角色、IF线、配套世界书、普通世界书与文风规范，生成极具代入感的入戏剧情。
【操作步骤】：
① 选择绑定的 Char（若选择多人卡，下方会自动展开子角色列表，勾选 1 位生成单人开场白，全选生成多人群像剧情）；
② 勾选开启配套世界书开关、普通世界书、或开启「专属文风描写加持」（可下拉选择文风库或导入外部文风）；
③ 设定字数区间（如 1000~3000 字），输入剧情大纲生成，右上角书本图标可打开开场白专属仓库。
7 & 8. char预览 & user预览 (数据管理中心)
【功能概述】：数据管理中心，具备自建分组、标签管理、单独/全量导出以及单份防拦截下载机制。
【操作步骤】：
① 点击展开可查看该角色名下所有绑定的世界书、IF线与世界观数据；
② 点击右上角「多选」或长按卡片进入批量模式，可批量移动分组、批量下载或删除；
③ 顶部可切换优先导出格式为 Word (.Docx) 或 纯文本 (.Txt)。
9. api (通道配置中心)
【功能概述】：配置生成工坊的 AI 通道，支持文本、视觉识图与 AI 生图三通道独立分离。
【操作步骤】：
① 填写 API URL（Base 格式，如 `https://api.openai.com/v1`）与 API Key；
② 如遇跨域问题可在代理框填入 CORS 中转；
③ 点击「远程在线拉取可用模型列表」，选择心仪模型后点击保存即可全局生效。
10. 数据与美化 (壁纸与防丢备份)
【功能概述】：自定义通透毛玻璃壁纸，支持全站数据一键打包备份与跨设备导入恢复。
【操作步骤】：
① 更换壁纸：上传图片并点击保存，主页两页与所有子页面将自动转换为高级毛玻璃折射效果；
② 全局备份：定期点击「导出备份 (.json)」保存到本地，换手机或清理浏览器缓存时点击「导入恢复」即可一秒还原全部人设、世界书与 API。
11 ~ 16. 灵感库 / 正则 / if线 / 关于工坊
· 灵感库：无灵感时可一键推演人设方向、世界观、城市名与工作地点，配有专属灵感仓库；
· 正则生成器：内置括号心理过滤、行首加人名等酒馆常用正则预设，支持自然语言定制高精度正则；
· if线人设生成器：绑定现有 Char，定制赛博朋克/性转/校园等平行宇宙反转人设，完成后可联动生成 if 线世界观；
· 关于工坊：查看制作者耳机信息、防倒卖举报通道与反馈群。
17. 人设整理 (双模式格式化清洗与一键转存)
【功能概述】：位于主屏幕第二页，将杂乱未排版的草稿一键梳理重构为规整专业人设卡。
【操作步骤】：
① 输入角色姓名，选择「纯整理模式」（忠于原作不增删）或「详细整理模式」（深度扩写丰富细节）；
② 粘贴原始文本，支持勾选破限生成，生成后可继续生成、修改人设或保存；
③ 点击右上角纸箱进入「整理人设卡库」，可多选批量下载、删除，并支持「一键转存至 Char 主库」（转存后立即可在 User生成、世界书、开场白、世界观中作为主角色选用）。
18. 文风生成 (专属笔触定制与开场白联动)
【功能概述】：位于主屏幕第二页，定制小说级行文笔触、电影感叙事或细腻心理流规范体系。
【操作步骤】：
① 填写文风主题与特征要求，点击生成完整的行文法则与示范段落；
② 生成后支持复制、导出 Docx/Txt，点击「直接保存进文风库」；
③ 右上角可打开文风仓库；保存后的文风可在「开场白生成器」中一键勾选下拉注入。
19. 模板自定义 (手写/AI设计模板与双向挂载)
【功能概述】：位于主屏幕第二页，自由设计专属于你的角色骨架结构，支持带作者署名。
【操作步骤】：
① 填写模板名称与作者署名（by谁）；
② 支持「手动编写」或切换至「AI辅助生成」输入题材需求让模型自动构思字段结构；
③ 点击保存时会弹出用途选择：「保存为 Char 角色模板」、「保存为 User 模板」或「两者双向通用」；
④ 保存后全自动同步插入对应生成器的模板选择菜单中，随时直接套用！
